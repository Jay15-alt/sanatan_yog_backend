Role-Based Access & Responsibilities 
1. ADMIN 
• Manage SubAdmins, Peeth, Shakha, SubShakha 
• Work Management (Proposed/Ongoing/Completed) 
• Payment Management (All levels) 
• Event Management (Create/Edit all events) 
• System-wide oversight 
• Admin can Add custom Contributor Category 
• Guests will be Managed Shakhas and assigned by shkha 
2. SUBADMIN 
• All Admin functions except SubAdmin management 
• Full access to Peeth, Shakha, SubShakha 
• Work, Payment, Event management 
• Guests will be Managed Shakhas and assigned by shkha 
3. PEETH (Division Level) 
• Manage Shakhas under their division 
• Create events (can only edit self-created) 
• Division-level reports and oversight 
• Cannot access other Peeths 
• Guests will be Managed  
4. SHAKHA (District Level) 
• Create/Manage SubShakhas in their district 
• Create/Manage Teams and Volunteers 
• Update Contributor Type (General → Trustee/Gruhini) 
• Verify PAN cards 
• District-level donation reports 
• Approve Field Worker commissions 
• Reassignment of Contributors to another Team 
5. SUBSHAKHA (Taluka Level) 
• Create/Manage Teams and Volunteers 
• Oversee donation collection 
• Manage contributor database 
• Taluka-level reports 
• Approve Field Worker commissions

Contributor Onboarding & Management 
Contributor Addition Methods 
Method 1: Website Self-Registration 
• User registers on website 
• Status: UNVERIFIED 
• Awaits volunteer verification 
• Account will be Created 
• Login will be of OTP  
• Unless verify no login 
Method 2: Volunteer Direct Addition (2-Step Process) 
STEP 1: Initial Account Creation (Without PAN) 
• Volunteer adds contributor with basic details 
• System generates Unique ID 
• Account created with Status: "PAN Pending" 
• Type: General Contributor (default) 
• Login will be of OTP 
STEP 2: PAN Card Update & Verification 
• Contributor logs in and uploads PAN card 
• Volunteer receives notification 
• Volunteer verifies PAN details 
• If approved → Status: VERIFIED 
Contributor Account Features 
• Profile with PAN status indicator 
• Transaction History (All donations with dates, types, amounts, receipts) 
• Donation management 
• Notifications and event invitations 
• Geo Location Coordinates but Optional (If Feasible Only)  
Contributor Types 
Classification Hierarchy 
All contributors start as General Contributor → Shakha upgrades to Trustee/Gruhini 
While adding the Contributor take the photo – Facial, Full photo, House Photo 
1. GENERAL CONTRIBUTOR (Default) 
• Standard contributor 
• No specific commitment 
• Single/occasional donations 
2. TRUSTEE (Regular Donor) 
• Regular, committed contributors 
• Upgraded by Shakha based on donation history 
• Recurring donation setup 
• Priority communication and recognition 
3. GRUHINI (Single Female per Family) 
• Rule: Only ONE Gruhini per family/household 
• Female contributor only 
• Upgraded by Shakha after verification 
• System validates no duplicate at same address 
• Special recognition and features 
Donation Types 
1. AMOUNT DONATION 
• (Online):-Cash/UPI-NEFT-RTGS/Bank Transfer/Cheque 
• Volunteer records in system 
• Instant receipt generated 
• Commission:    YES (Field Workers) 
2. RICE/GRAIN DONATION 
• Physical collection by volunteer 
• Quantity recorded (Kg) 
• System calculates monetary value (market rate) 
• Commission:    YES (Based on monetary value) 
• Minimum 1 KG for the Commission 
3. CUSTOM DONATION 
• Clothing, Books, Equipment, Services, etc. 
• Description and documentation 
• No monetary equivalent required 
• Commission:( Optional)

Attendance Workflow (Single Scan – User 
Based) 
STEP 1: Attendance Marking (Single Scan) 
Process: 
• User opens the website 
• User scans the Event QR Code displayed at the venue 
• System verifies the user and event 
System Records: 
• User ID 
• Event ID 
• Scan Time (timestamp) 
• Status: Present 
Only one scan is required per user per event. Duplicate scans 
are ignored. 
Attendance Status 
•    Present – Event QR scanned successfully 
•   Absent – Event QR not scanned 
Attendance Report Generation 
Individual Attendance Record 
For Each Volunteer / Member: 
• Event Name 
• Event Date 
• Scan Time 
• Status (Present / Absent) 
• Event Category

Volunteer / Member Dashboard 
Attendance History Includes:

• Total events participated 
• Attendance percentage
